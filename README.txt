日本語名・ガチャ分類対応（安全な暫定版）

GitHubリポジトリの一番上（ルート）にある update_events.py をこのファイルの内容で置き換えてください。
同じ階層に labels_ja.json を新規追加してください。
既存の sources.json / events.json / index.html は変更しないでください。

仕様:
- APIが明示する祈願・跳躍・バナー等は「ガチャ（新規・復刻未確認）」として扱います。
- 武器ガチャと分かる語がある場合は「武器・装備ガチャ」とします。
- 新キャラ/復刻キャラはAPIの曖昧な名前から推測しません。
- labels_ja.json に原文と対応する正式な日本語名・種類を手動登録したものだけ反映します。
- 現在の labels_ja.json は空なので、全イベントの自動日本語化は行いません。
- 今までのイベントIDは変更しません。

日本語名登録例（確認できた公式名称だけ登録してください）:
{
  "genshin": {
    "EXACT English source event name": {"name":"確認済み日本語名", "kind":"イベント"}
  },
  "wuwa": {}, "hsr": {}, "zzz": {}
}

分類可能なkind: イベント, ガチャ（新規・復刻未確認）, 武器・装備ガチャ, 新キャラ, 復刻キャラ, 新武器・装備, 復刻武器・装備, 報酬2倍, 報酬3倍, ログイン

GitHub Actions > Update Game Events > Run workflow 実行後、ログを確認してください。
