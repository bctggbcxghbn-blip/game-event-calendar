# NTE V59

公式Ver.1.4（2026-09-29公開）の告知から、期間が明記された14件を登録します。

- `python games/nte/nte_official_v59.py` はプレビューのみ。
- `python games/nte/nte_official_v59.py --apply` は events.json に反映。
- 同じIDで再実行しても重複せず、他ゲームのデータは変更しません。
- 「アップデート後」は開始時刻を推測しません。サーバー時間もJSTに換算しません。
- V59は**公式告知1ページを固定で取り込む初期版**です。将来のVer.1.5以降を自動発見する機能は未実装です。
- Wiki https://wikiwiki.jp/nte/ は今後の照合先候補ですが、この版の取得元には使いません。
